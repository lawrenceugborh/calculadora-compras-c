# Calculadora de Compras em C

Projeto acadêmico desenvolvido durante o segundo período de Ciência da Computação, no segundo semestre de 2025.

## Sobre o projeto

O projeto consistiu no desenvolvimento de uma calculadora para uma loja virtual fictícia, com o objetivo de calcular o valor total de uma compra, considerando os produtos selecionados e o custo do frete.

O valor do frete varia de acordo com a região de entrega e o peso total dos produtos.

## Funcionalidades

- Exibição de catálogo de produtos.
- Seleção de produtos e adição ao carrinho.
- Cálculo do valor total dos produtos.
- Cálculo do peso total da compra.
- Cálculo do frete conforme a região de entrega e o peso.
- Exibição do resumo da compra.
- Apresentação da data da compra e previsão de entrega.

## Tecnologias e conceitos utilizados

- Linguagem C.
- Estruturas condicionais (`if/else` e `switch/case`).
- Estruturas de repetição (`while` e `for`).
- Vetores e matrizes.
- Manipulação de strings.
- Biblioteca `time.h` para operações com data e hora.
